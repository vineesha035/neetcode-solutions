# NeetCode Solutions

My solutions to the [NeetCode 150](https://neetcode.io/roadmap) in Python, organized by pattern.

Every file opens with a short note covering the approach, why that data structure was chosen, the trade-off made, and the time and space complexity.

## Structure

Folders follow the NeetCode roadmap order. Files are named `<problem-number>-<slug>.py`, for example `01-arrays-hashing/0001-two-sum.py`.
